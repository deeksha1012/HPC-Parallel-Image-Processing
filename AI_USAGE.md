# AI Usage Disclosure and Review Log

This project was developed with the assistance of an AI coding agent (**Google Antigravity**) operating under the student's direct guidance, architectural requirements, and verification.

---

## 1. Scope of AI Assistance

- **Code Generation**: Scaffolding modules, pure-NumPy filter algorithms, multiprocessing execution wrappers, Streamlit UI/UX redesign, and ReportLab PDF report generation based on student specifications.
- **Test Suite Drafting**: Developing automated Pytest test fixtures, unit tests, and validation test cases.
- **Technical Documentation**: Formatting markdown guides, structuring theoretical viva explanations, and organizing project documentation.

---

## 2. What the AI Did NOT Do

- The AI **did not** execute any history-changing Git commands (`git add`, `git commit`, `git push`, or `git tag`). All repository version control actions were performed manually by the student.
- The AI **did not** fabricate, estimate, or hard-code any benchmark results, timings, speedup numbers, or hardware claims.
- All reported performance measurements, tables, and graphs were produced by running the benchmarking suite directly on the student's physical machine.
- The AI **did not** bypass or replace independent student evaluation, code review, or manual debugging.

---

## 3. Verification and Limitations

AI-generated code may contain subtle edge-case errors, performance bottlenecks, or incorrect assumptions regarding platform-specific behavior (such as macOS `spawn` process safety).
To guarantee academic integrity and software reliability:
- Every generated file was inspected and reviewed line-by-line by the student.
- The automated test suite (`pytest -v`) was executed locally on the student's machine to confirm mathematical and functional correctness.
- End-to-end interactive workflows were manually validated through the Streamlit dashboard and command-line interfaces.
